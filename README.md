# wifisignal
wifi signal meter for windows
# setup
clone the repo and run
```bash
pip install -r requirements.txt
```
and run
```bash
python wifi.py
```
or 
```bash
python wifi.py -live
```
| wifi.py | wifi.py -live |
|-|-|
| run for a any time period and get the result | see live signal (no final result) |
